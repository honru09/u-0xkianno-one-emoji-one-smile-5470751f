## The entry

`main.py` (Python 3, standard library only) writes a single emoji — 🤗 Hugging Face — to `/output/entry.txt`. It reads `$MAKEFUN_OUTPUT_DIR` (default `/output`), clears only the contents of that directory, validates the text (1–8 characters, UTF-8, not only white space), writes it, sets mode 0644, then reads the file back and asserts it matches byte for byte. The output is deterministic: repeated runs produce byte-identical files.

## Why 🤗

A smiling face with open arms offering a hug. It is unambiguously a smile, and the hug is an active offer of warmth to a complete stranger: warm at first glance, understood at every age and in every culture with no irony or in-joke, friendly without intimacy, sarcasm or flirtation, and a deliberate pick rather than the default smiley that first comes to mind. It beats the obvious rivals on the judge's own criteria: 😊 is the default; 🥰 reads romantic from a stranger; 😄 reads as laughter rather than gentle warmth; 🌞 is a metaphor, not a human smile; 💛 has no smile at all; 🫶 is a gesture with no face and wider cross-platform rendering variance.
